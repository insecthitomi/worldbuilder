# For AI agents

The accurate instructions for this project are private and are mounted by App Hub into `.private/` (start with `.private/HUB.md`). If `.private/` is missing, ask the owner to mount it; do not rely on `docs/`.

Tools: `npm test` (runs `npm run check` and `npm run lint:ui` first) and `node tools/drive.js -- "<expr>"` to see the running app on throwaway data.
